## Description
> PC+ is a web app that lets users browse a curated catalog of games, view game pages with images and ratings, and manage a personal virtual game library

## App Functions
1. Customer:
    1. Create/edit profile – Users can sign up, log in/out, and update basic account info.
    2. Browse games – Users can scroll through game listings, check categories, and open a game page to see details like price and rating.
    3. Buy games – Users add games to a cart and complete a fake checkout. After buying, the game shows up in their library and the button switches to Download Now.
    4. Leave reviews – Users can rate and review games they’ve bought.

2. Provider:
    1. Manage provider profile – Providers can create, edit, or remove their publisher profile.
    2. Add games – Providers can upload game listings with basic info like title, price, and images.
    3. View stats – Providers can see simple stats like downloads, ratings, and reviews.
    4. Reply to reviews – Providers can respond to feedback on their games.
