## TITLE
PC+

## TEAM MEMBERS
Michael Ramcharitar
Eddy Arriaga-Barrientos

## DESCRIPTION
PC+ is an online game store web application that mimics the interface of Steam. Users can look at all of the games on the site, look at a page for each game, add it to their cart, and “purchase” it. After clicking Buy Now on a game’s page, the UI changes to Download Now. The game can then be downloaded (greyed out for all but one flash game that is actually downloadable).

## APP FUNCTIONS
# Customer 
a. Create/modify customer profile - create an account, log in/out, update settings
b. View available services – navigate the site homepage sections (ex: Top Sellers and Random Picks), browse categories (ex: popular/new/clearance), and view individual game pages and descriptions
c. Subscribe/purchase – add to cart, complete checkout process (simulate), add to library/game collection
d. Write reviews

# Publisher
a. Create/modify/remove provider profile
b. Create services – create listings for games new to the website
c. View customer stats
d. Create/modify/remove game listings
